MLP 怎样
学习 XOR

两个输入不同时，XOR 输出 1。两类样本分居对角线，一条直线无法分开它们。这个实验用两个隐藏神经元解决分类问题。

2 个输入 → 2 个 sigmoid 隐藏单元 → 1 个输出。4 个 XOR 样本整批训练，二元交叉熵，Adam 学习率 0.03，共 300 轮。

四个样本的预测

输入标签类别 1 的概率预测

概率 ≥ 0.5 时预测为 1。准确率仅针对参与训练的四个样本。

参数怎样更新

前向计算先得到隐藏层输出 h = sigmoid(xW + b)，再得到分数 z = hv + b输出 和概率 sigmoid(z)。

输出分数的损失梯度是 p − y。反向传播用链式法则把它传回两个隐藏单元。对四个样本的梯度取平均后，Adam 更新权重和偏置。

第 0 轮，两个标签为 1 的样本预测概率约为 0.459，低于 0.5，因此分类错误。第 300 轮，两者都升至约 0.975，四个样本全部分类正确，平均损失也从 0.5620 降到了 0.0279。

例如，权重 W₁₁ 从 2.0000 增至 6.1371。切换到它的参数曲线，再拖动轮次滑块，可以对照同一轮的权重和预测变化。

完整 Python 源码

两份实现使用相同的 XOR 样本、2–2–1 网络和初始参数，以二元交叉熵和 Adam（学习率 0.03）训练 300 轮。PyTorch 用 autograd 计算梯度，TensorFlow 用 GradientTape。不同框架的 Adam 默认 epsilon 与数值计算可能带来细微差异。

PyTorch 完整实现

安装 PyTorch 后运行 python mlp.py，即可复现 300 轮训练并查看损失、预测概率和最终参数。

"""Reproduce the XOR experiment with PyTorch: python mlp.py."""
import torch
from torch.nn import Parameter
from torch.nn.functional import binary_cross_entropy_with_logits


def main():
    inputs = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
    targets = torch.tensor([[0.], [1.], [1.], [0.]])
    weights = Parameter(torch.tensor([[2., -2.], [-2., 2.]]))
    hidden_bias = Parameter(torch.tensor([-1., -1.]))
    output_weights = Parameter(torch.tensor([[3.], [3.]]))
    output_bias = Parameter(torch.tensor([-2.5]))
    optimizer = torch.optim.Adam(
        [weights, hidden_bias, output_weights, output_bias], lr=0.03
    )

    for epoch in range(301):
        hidden = torch.sigmoid(inputs @ weights + hidden_bias)
        logits = hidden @ output_weights + output_bias
        loss = binary_cross_entropy_with_logits(logits, targets)
        if epoch in (0, 100, 200, 300):
            probabilities = logits.detach().sigmoid().flatten()
            print(f"Epoch {epoch:3d} | loss {loss.item():.6f} | p(1) {probabilities.tolist()}")
        if epoch == 300:
            break
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    for name, value in (
        ("W", weights), ("b_hidden", hidden_bias),
        ("v", output_weights), ("b_output", output_bias),
    ):
        print(f"{name} = {value.detach().tolist()}")


if __name__ == "__main__":
    main()

TensorFlow 完整实现

安装 TensorFlow 后运行 python mlp_tensorflow.py。同样输出第 0、100、200、300 轮的损失和预测概率，以及最终权重和偏置。

"""Reproduce the XOR experiment with TensorFlow: python mlp_tensorflow.py."""
import tensorflow as tf


def main():
    inputs = tf.constant([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
    targets = tf.constant([[0.], [1.], [1.], [0.]])
    weights = tf.Variable([[2., -2.], [-2., 2.]])
    hidden_bias = tf.Variable([-1., -1.])
    output_weights = tf.Variable([[3.], [3.]])
    output_bias = tf.Variable([-2.5])
    parameters = [weights, hidden_bias, output_weights, output_bias]
    optimizer = tf.keras.optimizers.Adam(learning_rate=0.03)

    for epoch in range(301):
        with tf.GradientTape() as tape:
            hidden = tf.sigmoid(tf.matmul(inputs, weights) + hidden_bias)
            logits = tf.matmul(hidden, output_weights) + output_bias
            loss = tf.reduce_mean(
                tf.nn.sigmoid_cross_entropy_with_logits(
                    labels=targets, logits=logits
                )
            )
        if epoch in (0, 100, 200, 300):
            probabilities = tf.sigmoid(logits).numpy().flatten().tolist()
            print(f"Epoch {epoch:3d} | loss {float(loss.numpy()):.6f} | p(1) {probabilities}")
        if epoch == 300:
            break
        gradients = tape.gradient(loss, parameters)
        optimizer.apply_gradients(zip(gradients, parameters))

    for name, value in (
        ("W", weights), ("b_hidden", hidden_bias),
        ("v", output_weights), ("b_output", output_bias),
    ):
        print(f"{name} = {value.numpy().tolist()}")


if __name__ == "__main__":
    main()
