MLP 怎样
学习 XOR

两个输入不同时，XOR 输出 1。两类样本分居对角线，一条直线无法分开它们。这个实验用两个隐藏神经元解决分类问题。

训练进度

2 个输入 → 2 个 sigmoid 隐藏单元 → 1 个输出。4 个 XOR 样本整批训练，二元交叉熵，Adam 学习率 0.03，共 300 轮。

权重与偏置

四个样本的预测

输入标签类别 1 的概率预测

概率 ≥ 0.5 时预测为 1。准确率仅针对参与训练的四个样本。

参数怎样更新

前向计算先得到隐藏层输出 h = sigmoid(xW + b)，再得到分数 z = hv + b输出 和概率 sigmoid(z)。

输出分数的损失梯度是 p − y。反向传播用链式法则把它传回两个隐藏单元。对四个样本的梯度取平均后，Adam 更新权重和偏置。

第 0 轮，两个标签为 1 的样本预测概率约为 0.459，低于 0.5，因此分类错误。第 300 轮，两者都升至约 0.975，四个样本全部分类正确，平均损失也从 0.5620 降到了 0.0279。

例如，权重 W₁₁ 从 2.0000 增至 6.1371。切换到它的参数曲线，再拖动轮次滑块，可以对照同一轮的权重和预测变化。

完整 Python 源码

两份实现使用相同的 XOR 样本、2–2–1 网络和初始参数，以二元交叉熵和 Adam（学习率 0.03）训练 300 轮。PyTorch 用 autograd 计算梯度，TensorFlow 用 GradientTape。不同框架的 Adam 默认 epsilon 与数值计算可能带来细微差异。

PyTorch 完整实现

安装 PyTorch 后运行 python mlp.py，即可复现 300 轮训练并查看损失、预测概率和最终参数。

"""Reproduce the XOR experiment with PyTorch: python mlp.py."""  # 用 PyTorch 复现 XOR 实验，在命令行运行 python mlp.py。
import torch  # 导入 PyTorch，用于张量运算和自动求导。
from torch.nn import Parameter  # 导入 Parameter，将普通张量标记为可训练参数。
from torch.nn.functional import binary_cross_entropy_with_logits  # 导入直接接收原始分数的二元交叉熵函数，其内部计算比先求概率再取对数更稳定。


def main():  # 定义主函数，把数据准备、训练和结果输出组织在一起。
    inputs = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])  # 建立形状为 4×2 的输入张量，每行是一组 XOR 输入。
    targets = torch.tensor([[0.], [1.], [1.], [0.]])  # 建立形状为 4×1 的标签张量，输入不同为 1，相同为 0。
    weights = Parameter(torch.tensor([[2., -2.], [-2., 2.]]))  # 初始化 2×2 权重矩阵，行对应输入，列对应隐藏单元。
    hidden_bias = Parameter(torch.tensor([-1., -1.]))  # 初始化两个隐藏单元的偏置，计算加权和时会逐行广播。
    output_weights = Parameter(torch.tensor([[3.], [3.]]))  # 初始化 2×1 输出权重，将两个隐藏值组合成一个输出分数。
    output_bias = Parameter(torch.tensor([-2.5]))  # 初始化输出偏置，使每个样本的输出分数都加上这个值。
    optimizer = torch.optim.Adam(  # 开始创建 Adam 优化器，用来根据梯度更新参数。
        [weights, hidden_bias, output_weights, output_bias], lr=0.03  # 指定四组可训练参数以及学习率 0.03。
    )  # 结束优化器配置。

    for epoch in range(301):  # 依次计算第 0 至 300 轮的状态，第 0 轮是尚未更新参数的状态。
        hidden = torch.sigmoid(inputs @ weights + hidden_bias)  # 执行输入层到隐藏层的矩阵乘法，加偏置后经 sigmoid 得到 4×2 的隐藏值。
        logits = hidden @ output_weights + output_bias  # 组合隐藏值并加输出偏置，得到 4×1 原始分数 logits。
        loss = binary_cross_entropy_with_logits(logits, targets)  # 计算四个样本的平均二元交叉熵，此处直接输入 logits。
        if epoch in (0, 100, 200, 300):  # 仅在这四个轮次打印状态，减少输出量。
            probabilities = logits.detach().sigmoid().flatten()  # detach 切断打印数据与计算图的联系，sigmoid 将分数转为概率，flatten 展平。
            print(f"Epoch {epoch:3d} | loss {loss.item():.6f} | p(1) {probabilities.tolist()}")  # 输出当前轮次、平均损失以及每个输入属于类别 1 的概率。
        if epoch == 300:  # 检测是否已完成 300 次参数更新。
            break  # 结束循环，因此虽然记录 301 个状态，实际只更新参数 300 次。
        optimizer.zero_grad()  # 清除上一轮梯度，防止 PyTorch 默认的梯度累加影响本轮训练。
        loss.backward()  # 从损失反向传播，利用链式法则计算各参数的梯度。
        optimizer.step()  # 由 Adam 读取梯度并更新权重和偏置，进入下一个训练状态。

    for name, value in (  # 依次遍历参数名称和对应张量，准备输出训练后的数值。
        ("W", weights), ("b_hidden", hidden_bias),  # 为输入权重和隐藏偏置附上方便阅读的名称。
        ("v", output_weights), ("b_output", output_bias),  # 为输出权重和输出偏置附上方便阅读的名称。
    ):  # 结束参数列表，并开始处理其中每一项。
        print(f"{name} = {value.detach().tolist()}")  # 将参数从计算图分离并转为普通列表，打印最终学习结果。


if __name__ == "__main__":  # 仅在直接运行此文件时进入训练，被其他程序导入时不会自动执行。
    main()  # 调用主函数，启动完整实验。

TensorFlow 完整实现

安装 TensorFlow 后运行 python mlp_tensorflow.py。同样输出第 0、100、200、300 轮的损失和预测概率，以及最终权重和偏置。

"""Reproduce the XOR experiment with TensorFlow: python mlp_tensorflow.py."""  # 用 TensorFlow 复现 XOR 实验，在命令行运行 python mlp_tensorflow.py。
import tensorflow as tf  # 导入 TensorFlow，并使用常见缩写 tf。


def main():  # 定义主函数，统一组织数据、参数、训练和结果输出。
    inputs = tf.constant([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])  # 建立 4×2 的常量张量，每行包含两个 XOR 输入。
    targets = tf.constant([[0.], [1.], [1.], [0.]])  # 建立 4×1 的标签张量，输入不同为 1，相同为 0。
    weights = tf.Variable([[2., -2.], [-2., 2.]])  # 建立可训练的 2×2 输入权重矩阵，行对应输入，列对应隐藏单元。
    hidden_bias = tf.Variable([-1., -1.])  # 建立两个隐藏单元的可训练偏置。
    output_weights = tf.Variable([[3.], [3.]])  # 建立可训练的 2×1 输出权重矩阵。
    output_bias = tf.Variable([-2.5])  # 建立可训练的输出偏置，对所有样本广播相加。
    parameters = [weights, hidden_bias, output_weights, output_bias]  # 将四组可训练参数收集起来，后续统一求梯度和更新。
    optimizer = tf.keras.optimizers.Adam(learning_rate=0.03)  # 创建 Adam 优化器并指定学习率 0.03，其默认 epsilon 可能与 PyTorch 不同。

    for epoch in range(301):  # 依次记录第 0 至 300 轮状态，第 0 轮表示尚未更新参数。
        with tf.GradientTape() as tape:  # 启动自动微分记录器，记录作用于可训练变量的运算以便反向求导。
            hidden = tf.sigmoid(tf.matmul(inputs, weights) + hidden_bias)  # 计算输入乘权重加隐藏偏置，再用 sigmoid 得到 4×2 隐藏值。
            logits = tf.matmul(hidden, output_weights) + output_bias  # 组合隐藏值并加输出偏置，得到每个样本的原始输出分数。
            loss = tf.reduce_mean(  # 开始对四个样本的损失求平均。
                tf.nn.sigmoid_cross_entropy_with_logits(  # 使用直接接收 logits 的稳定二元交叉熵函数。
                    labels=targets, logits=logits  # 指定真实标签和当前原始输出分数，二者形状均为 4×1。
                )  # 结束逐样本交叉熵的计算。
            )  # 结束求平均，得到可用于反向传播的标量损失。
        if epoch in (0, 100, 200, 300):  # 仅在指定轮次打印实验状态。
            probabilities = tf.sigmoid(logits).numpy().flatten().tolist()  # 将分数转换为概率，再转为 NumPy 数组并展平为普通列表。
            print(f"Epoch {epoch:3d} | loss {float(loss.numpy()):.6f} | p(1) {probabilities}")  # 打印轮次、平均损失和四个样本属于类别 1 的概率。
        if epoch == 300:  # 检查是否已经完成 300 次参数更新。
            break  # 结束循环，避免再更新一次参数。
        gradients = tape.gradient(loss, parameters)  # 用记录的运算通过链式法则计算损失对四组参数的梯度。
        optimizer.apply_gradients(zip(gradients, parameters))  # 将每个梯度与对应参数配对，再由 Adam 更新参数。

    for name, value in (  # 遍历四组参数，输出训练后学习到的最终数值。
        ("W", weights), ("b_hidden", hidden_bias),  # 为输入权重和隐藏偏置提供打印名称。
        ("v", output_weights), ("b_output", output_bias),  # 为输出权重和输出偏置提供打印名称。
    ):  # 结束参数列表，开始逐项打印。
        print(f"{name} = {value.numpy().tolist()}")  # 将 TensorFlow 变量转为普通数值列表，并显示参数名称。


if __name__ == "__main__":  # 只有直接运行本文件时才启动训练流程。
    main()  # 调用主函数，完成 XOR 实验。
