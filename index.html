02 / Process

From an idea
to a page.

以下记录本次个人主页制作中已完成的真实步骤；每一步都围绕“明确需求—生成初稿—继续修改”展开。

确定页面目标与内容边界

将页面定位为个人主页和课程实践记录，确认展示姓名、专业、联系方式、网页制作过程与真实操作证据；不填写没有完成或无法证明的项目内容。

使用 Codex 制作静态网页

在本地创建 index.html，由 HTML 组织内容、CSS 控制视觉效果，并在浏览器中查看页面结果。

通过提示词迭代页面

根据页面用途提出具体修改：英文首页表达、深色科技感、多样化卡片布局、移除不想展示的内容，并保留可自行填写的联系方式入口。

03 / Prompt Refinement

Make the request
specific.

下面是根据本次作业整理出的可复用提示词。它不是运行结果或虚构经历，而是一份用于提高协作效率的需求模板。

个人主页制作提示词

请帮我制作一个个人主页，用于人工智能概论课程作业。

我的真实信息：姓名为 YQ Zhang，专业是数据科学与大数据技术；
本次实践使用 Codex 制作网页，并计划发布到 GitHub Pages。

页面需要包含：个人信息、网页制作过程、待补充的真实截图区域和联系方式。
联系方式公开 QQ 邮箱：2640325337@qq.com。

请使用深色科技感与多样化卡片布局，适配手机屏幕。
不要编造我未完成的项目、截图、数据、使用时长或心得。

提示词的关键：先给事实，再给目标、内容清单、风格与限制条件。这样生成的内容更容易核对和修改。
