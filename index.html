作业 01 / 与 Codex 协作

从不会做网页
到发布个人主页

  1. 先把第一页打开

    我一开始只想有个地方展示编程作品，但没做过网站。Codex 帮我写出第一版 index.html。在浏览器里打开它以后，我才开始把标题、内容和布局的要求讲具体。

  2. 预览后再提修改

    我先调整首页文案，再根据同学的参考页面把专题改成 AI Agent 实践记录。参考能帮我理解常见做法，课程的具体要求仍要自己确认。

  3. 把本地页面发布出去

    我在 GitHub 创建仓库，上传网页文件，再启用 GitHub Pages。这样老师和同学可以直接通过链接访问页面。

协作复盘

哪些事需要我来判断

先说清修改范围

结构、文案和样式一起返工会消耗更多 Token。我会先说清这次要改的位置和期望结果，再打开页面核对。

作业要求要向人确认

我记不清老师的要求时，Codex 无法从缺失的信息里补出答案。我需要跟同学核对，再决定页面该写什么。

检索结果要看来源

问题含糊或参考来源不可靠，检索结果就可能偏题。我会先缩小问题范围，再核对结论是否适合放进自己的作业。
